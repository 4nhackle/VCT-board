개인정보처리방침

시행일 2026-11-08 · 문의 biggest-cannula9b@icloud.com

1. 방문자 정보

  • 회원가입과 로그인이 없고, 이름·연락처 같은 개인정보를 사이트가 직접 수집하지 않습니다.
  • 방문 통계를 위해 GoatCounter(goatcounter.com)를 사용합니다. 쿠키를 쓰지 않으며, 방문자를 식별하는 정보를 저장하지 않고 방문 수, 본 페이지, 유입 경로, 브라우저·기기 종류, 화면 크기, 대략적인 국가 같은 집계 정보만 처리합니다. 광고는 쓰지 않습니다.
  • 방문 측정과 페이지 성능 확인을 위해 Cloudflare Web Analytics를 함께 씁니다. 방문 지표, 페이지 로딩 시간, Core Web Vitals(페이지 사용 체감 성능 지표)를 측정합니다. Cloudflare는 이 측정이 쿠키나 로컬 저장소를 쓰지 않는다고 설명합니다(cloudflare.com/web-analytics). 그 밖의 처리와 보관 기간은 Cloudflare 개인정보처리방침을 따릅니다.
  • 사이트는 GitHub Pages로 제공됩니다. 접속 기록(IP 주소 등)은 GitHub가 서비스 운영을 위해 처리할 수 있으며, 이 사이트 운영자는 그 기록을 받지 않습니다.

2. 건의 기능

건의 탭에는 두 가지 보내기 방법이 있습니다.

  • 보내기 버튼: 방문자가 쓴 내용, 함께 적은 근거 링크(있을 때), 고른 건의 종류가 건의 전달 서비스 web3forms(api.web3forms.com)로 전송되고, web3forms가 운영자의 메일로 전달합니다. 이름이나 메일 주소는 따로 입력받지 않습니다. web3forms가 처리하는 접속 정보와 보관 기간은 web3forms 개인정보처리방침을 따릅니다.
  • 메일 앱으로 보내기 버튼: 방문자의 메일 앱이 열리고, 방문자가 직접 메일을 보냅니다. 이때 사이트는 내용을 전송하지 않습니다. 내용 복사 버튼은 글을 클립보드에 복사할 뿐 어디에도 보내지 않습니다.

받은 내용은 답변과 개선에만 쓰고, 처리가 끝나면 지웁니다. 메시지에 개인정보를 적지 마세요.

3. 사이트에 실리는 선수·코치 정보

  • 이름, 소속, 포지션, 국적, 이적 상태처럼 공개 보도와 공개 자료에서 확인되는 정보를 정리합니다. 본명, 생년월일, 경력 등이 포함될 수 있습니다.
  • 각 정보에는 출처 링크를 두며, 출처에서 확인되는 사실 값만 싣습니다. 보도 전문을 옮기지 않습니다.
  • 잘못된 정보의 정정이나 삭제는 본인과 대리인 모두 요청할 수 있습니다. 메일로 알려 주시면 확인 후 지체 없이 처리합니다. 보도 단계의 소식은 공식 발표 전이라 바뀔 수 있다고 사이트에 표시합니다.

4. 보유 기간과 제3자 제공

방문자에 대해 이 사이트가 보관하는 개인정보가 없습니다. 위 1항의 방문 통계 처리(GoatCounter, Cloudflare Web Analytics)와 2항의 보내기(web3forms 경유) 외에 방문자의 정보를 제3자에게 제공하거나 광고에 쓰지 않습니다. 1항과 2항에 적은 서비스가 처리하는 정보의 보관 기간은 각 서비스의 방침을 따릅니다. 5항의 후원 링크를 누르는 것은 제공이 아니라 해당 서비스로의 이동입니다.

5. 후원

후원은 외부 서비스인 Ko-fi와 카카오페이에서 처리됩니다. 이 사이트는 결제 정보와 후원자 정보를 받거나 저장하지 않습니다. 후원 링크를 누르면 해당 서비스로 이동하며, 그곳의 개인정보 처리는 각 서비스의 방침을 따릅니다.

6. 방침의 변경

광고를 도입하거나 분석 도구를 바꾸는 등 처리 내용이 바뀌면 이 문서를 먼저 고치고 시행일을 새로 적습니다.
