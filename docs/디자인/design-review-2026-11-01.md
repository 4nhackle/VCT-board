## 개선 항목

### P1 — 미확정 이적에 확정 체크가 표시됨

**재현:** #players에서 OXY 행을 확인합니다. conf=R(단일 출처)이며 공식 발표 전이라고 적혀 있지만, 초록 체크와 “Sentinels 합류” 상태가 보입니다.

**위치:** [model.js](../js/model.js#L192), [style.css](../css/style.css#L132), [players.json](../data/players.json#L4)

**개선:** conf=R에는 “보도” 같은 임시 상태를 표시하고, 확인된 이적에만 체크와 초록색을 사용합니다.

### P2 — 반복되는 긴 메모가 목록 훑기를 방해함

**재현:** 선수 목록에서 FURIA 선수 행을 연속해서 봅니다. 철수 배경 설명이 여러 행에 반복되어 행이 길어집니다.

**위치:** [row.js](../js/components/row.js#L31), [players.json](../data/players.json#L12), [style.css](../css/style.css#L142)

**개선:** 목록에는 선수별 한 줄 요약을 두고, 공통 배경 설명은 상세 화면에 모읍니다.

### P2 — 일정이 시작 날짜순이 아님

**재현:** 일정 탭에서 1월 일정을 확인합니다. 1월 14일 시작의 4개 지역 Kickoff가 1월 11일 시작의 Pacific Kickoff보다 먼저 표시됩니다. 렌더러가 데이터 순서를 그대로 사용합니다.

**위치:** [schedule.js](../js/views/schedule.js#L27), [schedule.json](../data/schedule.json#L7)

**개선:** 파싱한 시작 날짜로 정렬하고, 전체 일정과 지역별 일정의 겹치는 표현을 정리합니다.

### P3 — 갱신 시각에 시간대가 없음

**재현:** 페이지 상단의 “2026-11-01 13:58 기준입니다”에서 시간대 표기를 찾을 수 없습니다. 여러 지역의 보도 시각과 비교할 때 기준이 모호합니다.

**위치:** [index.html](../index.html#L22)

**개선:** 2026-11-01 13:58 KST 기준으로 표시합니다.
