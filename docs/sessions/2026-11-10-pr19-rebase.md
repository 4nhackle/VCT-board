# PR 19 재작업: 로스터 탭 디자인을 origin/main 위로 옮기기 (2026-11-10)

## 목적
지시문 `docs/instructions/PR19-rebase-on-main.md` 대로, 충돌난 `design/roster-tab`(0130bf6)을 그대로 리베이스하지 않고 `origin/main`(018f3e1)의 `js/views/roster.js` 를 기준으로 세 가지만 옮긴다. 검색(PR 22)·이적 따라가기(PR 23) 동작과 `li.row.roster` 목록 모양은 그대로 둔다.

## 기준과 브랜치
- 새 로컬 브랜치 `design/roster-tab-v2`, `origin/main`(018f3e1)에서 땀.
- 옛 `design/roster-tab`(워크트리 `VCT-board-pr19`)은 그대로 둔다.
- 푸시·PR·병합은 하지 않았다. 지시문이 "사용자가 말하기 전에는 푸시·병합하지 않는다"고 한다.

## 바꾼 파일
- `css/style.css`
  - `.move`, `.move .team`: 글자 크기 `--text-small` → `--text-body`.
  - `.move .route { font-size: inherit; }` 추가. 행 안의 경로 `.route` 가 작은 글씨를 고집하지 않게 한다.
  - `.th .in { color: var(--status-signed-fg); font-weight: 700; }`, `.th .out { color: var(--status-left-fg); font-weight: 700; }` 추가.
- `js/views/roster.js`: 팀 머리 `.n` 을 `<span class="in">+i</span> <span class="out">−o</span>` 로 바꿨다. `t("roster.inout", …)` 호출을 없앴다.
- `js/i18n/ko.js`, `js/i18n/en.js`: `roster.inout` 키 삭제. 다른 곳에서 쓰지 않는다(`grep -rn "roster.inout" js scripts` 로 확인).
- `scripts/test.mjs`: `rosterHTML` 시험의 두 단언을 새 마크업에 맞췄다.
  - `/\+0 \/ −0/` → `/<span class="in">\+0<\/span> <span class="out">−0<\/span>/`
  - `/\+1 \/ −2/` → `/<span class="in">\+1<\/span> <span class="out">−2<\/span>/`
  - 지시문은 검색·지역 시험을 "그대로 통과"하라고 했다. 검색·지역 거르기 단언(팀 전체, 인물만, 빈 문구, 대소문자, 지역 머리 개수)은 그대로이고, 인원 표시 단언 두 줄만 마크업에 맞췄다.

## 항목별 처리
1. 이동 칸 글자 크기: 완료(CSS).
2. 팀 머리 +i/−o 색: 완료. `+`·`−` 기호를 남겼다(색만으로 구분하지 않게 함). 지시문 마크업대로 `/` 구분자는 뺐다.
3. 탭 힌트: 이미 고쳐져 있다(`js/main.js` 로스터 분기 41행이 `tab.hint` 를 붙인다). 고치지 않았다 → "already fixed".
