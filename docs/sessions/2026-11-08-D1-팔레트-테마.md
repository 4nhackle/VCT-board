## 결정과 이유

- 강조색 라이트 값은 지시문의 `#C42F3B` 를 그대로 썼다. 대비 5.04:1 로 4.5:1 을 넘어 조정하지 않았다. 조정한 값은 없다.
- `--green-600` 은 이제 신호 완료 띠 색(`#1E8A5A`)이다. 강조색이 아니다. 이름은 그대로 두었다(녹색 계열이 맞다). `--green-on` 은 강조색의 글자색으로 쓰였으므로 `--coral-on` 으로 옮겼다.
- `--red-*` 는 경고 색이라 `--plum-*` 로 바꿨다. 이름이 맞지 않으면 나중에 헷갈린다.
- `--color-line-strong` 은 지시문대로 `--neutral-600`(본문 흐린 글자색)을 가리킨다. 대비는 3:1 을 넘는다.
- 테마 적용 스크립트는 첫 인라인 스크립트 안에 넣었다. 깜빡임을 막으려면 CSS 보다 먼저 돌아야 한다. 언어 이동이 `return` 으로 끝나므로 테마 코드는 그보다 앞에 두었다. 저장소 오류는 테마 블록의 `try` 가 막는다.
- `theme-color` 두 개는 머리 스크립트가 `DOMContentLoaded` 에서 맞춘다. 헤드 스크립트 시점에는 메타 태그가 아직 없다. 시스템 값일 때는 메타 기본값(라이트·다크)을 그대로 둔다.
- 개인정보·이용약관 페이지에는 전환을 두지 않았다(지시문). 저장된 테마만 따른다.
- 머리의 `.top-prefs` 는 데스크톱 오른쪽 열 첫 줄, 600px 이하에서는 오른쪽 끝 줄이다. 375px 에서는 후원 메뉴가 첫 줄, 테마·언어가 둘째 줄 오른쪽으로 내려간다. 두 묶음의 합이 한 줄에 안 들어가서 그렇다.
